## New in 2.0.0
If you already have 1.7.0: the new parts are the memory fixes, the memory limit's new numbers, the colour-custom fix and the shorter menu. Everything else below was in 1.7.0.

**Memory no longer keeps growing**
- In long sessions, above all in boss fights where players keep changing gear, Mugetsu held on to item files that nobody was using any more, and the number in Task Manager only went up (in one session from 0.3 GB to 2.8 GB in eight minutes). Unused item files are now freed within about a minute. In the same kind of session Task Manager now stays around 1 to 1.3 GB in crowded rooms.
- The short pause this clean-up causes every few seconds is smaller than before, although it checks far more files each time.

**Much faster in crowded rooms**
- The game's own work for each frame takes less than half the time it did: parts of the screen where nothing is happening are skipped instead of being gone through again every frame.
- The finished picture is sent to the screen on a thread of its own while the game already works on the next frame.
- Glows, blends and cached pieces need fewer drawing steps.
- On the test laptop (built-in Intel graphics, Quality Low), a full Yulgar went from 15-18 pictures a second in 1.6.0 to 19-24, and the game's share of each frame from about 20 ms to about 8 ms.

**Performance mode (new)**
Right-click the game > Performance mode: Off, Balanced or Fast. It draws the game with fewer pixels (Balanced 85%, Fast 70% of the window's width and height) and stretches the picture over the window: a little softer, and faster. It helps most on laptops and built-in graphics (on the test laptop, Fast gave about 28% more pictures a second in a crowd). On built-in graphics at Quality Low, Mugetsu offers the mode once when it notices the game running slowly.

**DirectX 12 is now the default on Windows**
In the game it is as fast as Vulkan or faster, and the graphics driver holds far less memory. Vulkan is still there: it is used automatically when DirectX 12 is not available, and you can choose it in the menu.

**Memory limit (new)**
Right-click the game > Memory limit: Off, 1 GB, 2 GB, 3 GB or your own number. It counts the same number Task Manager shows for Mugetsu, and the menu shows that number. When Mugetsu goes over the limit, it frees what the game is not using.
- "Free memory now" does the same on request, and also frees at once every item file that no player on screen is using any more.
- Laptops with built-in graphics keep much less spare graphics memory than before (1.6.0 treated them like a dedicated card).
- If you set a limit in 1.7.0, check it: 1.7.0 counted a larger number (graphics memory included), so the same limit is looser now.

**Frame pacing and an FPS limit**
With frame interpolation on, frames are paced to your screen by default. A new "Uncapped" choice (right-click > Frame pacing) sends frames as fast as your PC can make them, meant for G-Sync and FreeSync screens, with an optional FPS limit (presets or your own number). Both settings only show while frame interpolation is on.

**A tidier menu**
The right-click menu shows one line per setting, with a short explanation of the setting you point at. The Edge smoothing setting is gone: Mugetsu always uses its Flash-style smoothing now.

**Runs on any 64-bit processor**
Mugetsu no longer needs a processor with AVX2, so older PCs can run it.

**Entering rooms**
- A new room's shapes are taken in faster, and the picture waits a moment (a tenth of a second at most) for the map's pieces instead of showing them black first.
- Inside a room, a very detailed item that is not ready yet appears a moment later instead of freezing the game.

**Looks**
- Flash-style edge smoothing: thin shapes keep their true weight, and Medium quality has a lighter smoothing of its own.
- The darkened half of skill and aura icons is sharp now.

**Fixes**
- Colour-custom armour, hair, helms and capes no longer show their original colours for a moment when a player appears on screen.
- A crash that could happen while closing the game.
- A rare crash while starting with DirectX 12.
- Very detailed animated shapes no longer stall the game while they are prepared.
- Built on a newer Ruffle (10 November 2026), with its fixes.

**Good to know**
- Frame interpolation is still off by default. Turn it on with right-click > Frame interpolation.
- The FPS counter counts the frames sent to your screen. With the default pacing it can show a lower number than 1.6.0 did in the same room; the game is not slower.
- A memory limit lower than what a room needs cannot be met: Mugetsu frees what it can and then waits longer between tries. "Free memory now" cannot go below what the room on your screen needs either.
- If something looks wrong after this update, two empty files next to Mugetsu.exe switch single changes off (restart after adding one, and please tell us what you saw): `msaa` brings the old edge smoothing back, `no-early-scripts` turns the colour-custom fix off.
- Opening the Book of Lore still pauses the game for a moment.
