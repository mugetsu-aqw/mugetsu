## New in 2.0.3
Six fixes since 2.0.1. Everything else is as in [2.0.0](https://github.com/mugetsu-aqw/mugetsu/releases/tag/v2.0.0).

2.0.2 was withdrawn shortly after its release: it made some rooms (/ultraalteon, /ultradrakath) darker than they should be in larger windows. If you downloaded 2.0.2, please replace it with this version.

**Fixed**
- **HP and mana showing 0.** With frame interpolation on, the target box could show 0 for a newly selected target until the fight began (typically for the first target after a kill). The numbers are right from the start now.
- **Hidden things staying on screen a moment too long.** With frame interpolation on, something the game hid between two of its frames (the target box as the target dies) could be drawn for up to one more frame. It disappears at once now.
- **Glowing gear resting slightly off.** With frame interpolation on, a glowing item whose parts had just moved could come to rest a little short of its final position until it moved again. It settles where it belongs now.
- **Colourless rune words in /spellcraft.** They glow red and green again. Mugetsu did not draw this kind of glow at all; it does now, wherever the game uses it.
- **Wrong colours on screens larger than 1080p.** On 1440p and 4K screens some rooms lost colour tints and shading that a 1080p screen shows (/sevencircleswar looked bright blue instead of dark teal). A room now looks on a bigger screen the way it does on a 1080p one; the restored tints are drawn slightly softer. Up to 1080p nothing changes. An empty file named `no-cache-reduction` next to `Mugetsu.exe` turns the change off.
- **Half-black screenshots and streams** (DirectX 12 with Uncapped frame pacing). Mugetsu no longer starts each frame from a black picture in that mode, so a capture that reads a frame a moment late sees the previous picture instead of a half-drawn one. We could not reproduce this on our own PCs, so please tell us if you still see it. An empty file named `no-capture-safe` next to `Mugetsu.exe` turns the change off.
